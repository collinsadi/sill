# Bundled typefaces

None of the three faces the design specifies are installed on a stock macOS system, so they
ship with the app. Substituting system fonts would have been a silent design change.

| File | Family | Licence |
|---|---|---|
| `IBMPlexSans.ttf` | IBM Plex Sans, variable | SIL Open Font Licence 1.1, Copyright 2019 IBM Corp. |
| `DMMono-Regular.ttf` | DM Mono | SIL Open Font Licence 1.1, Copyright 2020 The DM Mono Project Authors |
| `Fraunces.ttf` | Fraunces, variable | SIL Open Font Licence 1.1, Copyright The Fraunces Project Authors |

Full licence text in `OFL.txt`.

Fraunces is the **variable** build. The design specifies `SOFT 60`, which controls how swollen
and rounded the terminals get, and that swell is the entire reason the face was chosen. Figma
only ever had static instances, so the app is the first place it renders as designed.
